# Mini Task Manager (React + AG Grid + Node.js/Express + JSON)

A full-stack task manager app built with **React (frontend)** and **Node.js/Express with JSON file persistence (backend)**.  
Supports CRUD operations, task dependencies, validation rules, and RTL toggle.

---

## ✨ Features
- **CRUD:** Create, inline edit, delete tasks (saved in a JSON file).
- **Dependencies:** Add by task IDs, view chips with tooltips, blocked tasks 🔒.
- **Validation:** Prevents invalid titles, wrong dates, incomplete dependencies, or dependency cycles.
- **Grid:** Sorting, filtering, inline editing, keyboard-friendly.
- **RTL Support:** Toggle with `Ctrl+Alt+R` or via button.

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/mini-task-manager.git
cd mini-task-manager
```

### 2. Frontend Setup (React + AG Grid)
```bash
cd frontend
npm install
npm start
```

### 3. Backend Setup (Express + JSON)
```bash
cd backend
cd frontend
npm install
npm node index.js
```
